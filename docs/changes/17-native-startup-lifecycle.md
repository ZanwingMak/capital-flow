# 节点17：原生CI启动与退出边界

首轮原生CI暴露Windows测试使用Unix绝对路径，以及控制管道读取与启动预算不足的边界。测试路径改用平台原生绝对Unicode目录。

控制读取提前到服务导入之前：冷导入卡住时，宿主EOF仍会触发退出看门狗。首报文期限保持10秒，整个启动期限25秒（宿主预算30秒），20秒未就绪输出线程栈。Windows正常清理HTTP与协议后直接结束自身进程，避免关闭正在阻塞读取的CRT stdin描述符或解释器终结卡住。测试的13秒无初始化退出断言保留。

子进程测试stderr写入隔离日志，避免无人读取PIPE造成堵塞；失败附日志末尾。新增慢导入/EOF等回归。真实本机Python全量197项通过，源码入口协议冒烟9项通过。原macOS CI的确切阻塞栈尚未知，不归因于未证实的Python版本差异；后续原生CI使用新增诊断继续验证。
