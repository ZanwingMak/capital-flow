# 节点16：指标接入与异步错误边界

将自编指标接入行情鉴权、单工作线程异步任务和静态资源白名单，首页新增指标研究入口。指标计算只接收按市场日历截断的已完成日线，请求截至日与实际样本末日分别保留。桌面资源显式清单包含指标模块和页面资产。

独立审查复现共享异步任务将 ValueError/RuntimeError 正文直接返回客户端：上游异常可能包含路径或凭据。改为按错误类别返回固定中文消息，保留400/503/502区别；请求参数在提交前的明确校验仍可返回具体业务提示。未知异常仅记录异常类别。

新增合成测试先复现两类异常正文泄露，再确认修复；同时验证周一请求只向loader索取前一完成交易日，响应仍保留原请求截至日。全量Python193项通过。测试不读真实账户或密钥。

限制：富途逐根数值兼容性未认证。真实历史回测不能证明稳定优势，详见指标节点。macOS仅ad-hoc签名，Windows须经原生CI验证，不以交叉编译替代运行验收。
