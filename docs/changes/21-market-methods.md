# 节点21：六类市场方法研究

## 问题与行为

在事件研究中增加“多方法研究”入口，保留现有自定义指标。六类方法使用同一份已完成美股日线，显示候选、确认时点、来源与限制；不合成所谓共振胜率。

- ICT：扫价、结构转换与FVG回测的日线规则子集。
- PA：区间突破后回测确认，吞没与影线仅观察。
- 威科夫：局部Spring/Upthrust、缩量测试与SOS/SOW确认，不宣称完整阶段。
- 均值回归：布林带与RSI，加入ADX和均线斜率过滤。
- 艾略特：六摆点推动浪几何候选，不提供交易绩效。
- 订单流：仅读取同日已有完整SIP尾盘20分钟逐笔与报价归档；方向为估算，缺失不补零。

## 执行与兼容

新增鉴权异步 `/api/methods`，复用作业进度与已授权行情读取。仅支持US日线，固定四类正股多头研究策略；收盘确认、次开盘执行，成本显式传入，最长20根。参考止损与目标未模拟实际触发成交。桌面资源清单包含新增静态资源及Python模块；本节点同步源码不等于发布新的原生安装包或重启本机服务。

摆点在右侧两根确认后才可知；候选不回填为极值当日交易。当前复权快照并非严格点时数据；选股、幸存者偏差与小样本仍存在。

## 验证记录

新增前端边界测试，核对URL凭据与非安全远程连接拒绝、响应未来日期及虚假确认时点拒绝；连同原指标DOM测试20项通过。依赖安装于项目之外的隔离缓存目录。新增后端24项方法测试，覆盖四类策略真实合成确认到次开盘执行、成本、持有上限、退出、前缀因果性、参数与截止边界、API鉴权和来源限制、订单流时间；全量Python 234项通过。修复请求规范化后的market未完整传递到loader与报告的问题。

真实QQQ行情试跑得到四种策略零成交，经核对无多头主入场：ICT与PA只有看跌退出确认，威科夫候选未形成SOS，均值回归仅有退出穿越。合成行情测试证明四类策略可正常确认并次开盘执行，未修改阈值强求真实样本成交。观察事件数量不能作为实际交易数量或已验证优势。本节点不宣称任何方法已证明稳定盈利或胜率。
