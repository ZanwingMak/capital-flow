# 节点11：持仓压力实验室

日期：2026-11-09。实现基于 `main b48bfc5`。下文区分开发阶段离线测试与父代理独立运行验收；最终发布保留本节点提交。

## 交付

在既有本机私有弹窗的账户区后增加“持仓压力实验室”。原生JS/CSS，无依赖安装。支持主动载入当前授权快照、人工USD参考价格和带时区参考时间、-5/-10/-20%假设预设、手填全局及独立单股冲击、逐股和底仓/短线/未分组汇总、清除覆盖及清空实验。

突出“假设情景、不是预测”。只显示已覆盖正股参考市值和情景美元影响，金额到分；不将成本当价格、不计算账户NAV或部分覆盖的组合收益率。未知/部分数量、价格缺失、无效冲击逐行显示原因，缺口与真正0分开。冲击支持-100%，有效范围为-100至+1000%；乘积、下溢和累计金额均检查，超限不继续展示汇总。

账户切换和刷新开始时立即清空，过期异步快照不能跨账户采用。沿用原生close和open属性观察清理，关闭后所有动态实验DOM与值被擦除。实验室不持有API客户端，只读现有授权上下文；不改写快照、账本或分组，无网络、持久存储、日志、导航和导出。

变更文件：`dist/stress-lab.js`、`dist/private.js`、`dist/index.html`、`dist/private.css`、`server.py`、`tests/test_stress_lab.js`、`README.md`，以及本文和[功能说明](../stress-lab.md)。服务端仅增加JS静态白名单，私有API保护与既有市场API保持原有行为，未变更数据库或schema。原节点1至10文档没有修改。

## 父代理浏览器验收清单

仅在父代理控制的合成账户环境验收，不复用真实持仓。

1. 打开本机私有弹窗，开启既有会话并选择合成账户；实验区仅显示待载入入口，点击“载入当前账户持仓”前没有任何持仓行。核对来源日期与revision，价格/时间/全局冲击均未预填。
2. 准备A底仓2股、B短线3股、C未分组1股，手填参考价格100/20/40和过去的有效带时区时间。选择-10%并计算：覆盖3/3，参考市值300.00、情景270.00、变化-30.00；分组变化分别-20.00/-6.00/-4.00。把A单股冲击改成-100%，确认旧结果立即移除，重算变化-210.00；再填写0，确认该股保持不变。清除单股覆盖后回到全局冲击。
3. 清空B参考价格：覆盖2/3、未覆盖包含B、B原因明确，已覆盖参考市值240.00、变化-24.00。所有价格清空时没有可用总额。分别试空全局、畸形数字、负价格、-100.01%与1000.01%，应有可读错误，不能变成0。明确输入0与缺失呈现不同。
4. 使用合成的未知数量/known_partial/position_gaps上下文，确认已知部分7股或0股都不作为截止总量；未知分组归入未分组。账本数量、成本和分组不因计算变化。
5. 填入实验后刷新版本（包含revision不变的刷新）、切换账户、关闭并重新打开弹窗：旧值和结果全部清空。后台标签页移除dialog.open，检查实验容器和输入已清理；刷新在途切换账户或关闭后，迟到响应不能恢复旧实验。
6. 检查窄屏横向滚动、键盘聚焦、输入标签、状态提示和长标的文本换行。恶意合成标的只显示文字，不创建图片/脚本。检查载入、编辑、计算没有新增网络请求，没有持久存储或URL变化。
7. 复验GitHub Pages无法访问本机私有API，以及私有API原有Origin/Host/令牌保护；复验既有台账追加、CSV预览和研究冻结。父代理记录结果后处理提交、GitHub和现有live服务发布。
