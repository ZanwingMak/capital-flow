# 节点 22：四站研究与宏观 / 市场结构背景

## 问题与结果

原有资金流、技术方法和私有事件记录缺少独立的宏观与聚合市场结构入口。本次研究 SqueezeMetrics、FinancialJuice、Webull 与 FRED 的官方页面、数据口径及权限，将可可靠落地的部分接入「事件研究 → 宏观与市场结构」。详见[四站研究与工作流](../market-context.md)。

- 新增固定官方来源的市场背景服务与鉴权异步 `/api/market-context`，不依赖 OpenD 取宏观数据。
- FRED 八项观测：DGS10、DGS2、T10Y2Y、DFII10、BAMLH0A0HYM2、FEDFUNDS、CPIAUCSL、PCEPILFE。保留单位、频率、观测日、实际取数时间；CSV 不可用时严格验证官方序列页身份及最新观测。系统 curl 为 Python TLS 失败的有界回退，不发送凭据、不跟随重定向。
- 数据为最新修订版本，明确非 PIT。最新页面无法覆盖更早历史日时返回缺失，不推测历史值。报告生成时间与缓存取数时间分开。
- SqueezeMetrics 自动获取默认关闭，书面许可须由部署方确认后显式开启；手动官方 CSV 仅在浏览器内存预览，未上传、未持久化。DIX / GEX 不当作机构净买入或个股期权墙。
- FinancialJuice、Webull 提供官方入口及独立订阅权限说明；未声称接入付费新闻、语音、日历流或券商行情。
- 新窗口支持取消、日期/连接变化时清理、关闭恢复焦点、来源安全链接与窄屏布局。桌面资源清单纳入新模块；未创建新正式安装版本。

## 验证

- 项目 Python 完整回归：257 项通过。
- Node / DOM 全套：99 项通过，包括真实共享 202 → jobs 轮询、日期身份、取消竞争、缺失与真实零、CSV 解析与隐私清理、生成时间与取数时间区分。
- 独立本机真实 HTTP：`/api/market-context` 返回 200，5.63 秒取得 8/8 FRED 观测，均为 `latest-page`。日级观测为 11 月 18—19 日，FEDFUNDS / CPI 为 10 月，核心 PCE 为 9 月；非实时行情。默认 SqueezeMetrics 状态为 `manual-or-licensed`。
- 同进程请求 2000-01-03：HTTP 200、0 项可用，保持缺失，未把当前页面回填为历史。
- 浏览器 390 像素宽度无横向溢出，窗口关闭恢复入口焦点；合成 CSV 仅用于交互测试。真实数据验证与合成回归分开。

## 兼容与限制

现有资金流与多方法研究 API 保持兼容；共享轮询增加新端点映射。仅支持美国背景序列，不接受任意 URL 或 API key 参数。固定来源、六并发、响应大小限制、有限超时及成功 / 失败缓存防止重复请求堆积。

页面结构和公开下载方式可能变化，解析失败时逐项降级。没有部署方许可不启动 SqueezeMetrics 自动采集；没有供应商订阅不启动 FinancialJuice / Webull 数据流。未将 FRED 的当前修订值接入历史策略回测。公开仓库不包含真实持仓、券商材料、运行缓存、采集结果或凭据。运行服务升级与源码同步分别验证，既有 v0.1.1 安装包不代表包含本节点。
