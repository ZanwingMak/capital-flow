# 节点13：真实交易日历半日市编码

真实富途日线与request_trading_days交叉核验时发现，SDK以MORNING标识美股半日市，例如2023-11-24、2024-07-03；现有代码仅识别HALF，导致已结束日线判断、分钟尾盘收盘时间和仓库外报告门控漏掉这类交易日。

兼容MORNING和旧HALF：美股13:00、港股12:00，WHOLE保持原定义，未知类型仍不推断。Python回归先复现分钟closeTime=None及已结束日选择失败，修复后3项通过。仓库外盘前/盘中gate单独实跑：MORNING 12:59仍检查、13:01停止、08:30盘前有效。收盘采集器同样增加MORNING映射，修改前已备份。

父代理实际采集六只美股/ETF，各827根（2023-07-25至2026-11-06），逐根OHLC范围、有限正价格、非负成交量、唯一递增日期检查通过；交易所日历核验827交易日，六标的均无缺失或额外日期，包含7个MORNING半日市。原始授权行情留在本机scratch，不上传或附在公开仓库。日线为当前版本前复权，非历史时点复权版本，也不能因此宣称无幸存者偏差或可获利。

本节点只修已证实的SDK枚举兼容问题；指标本身回测与桌面产物验收另行记录。
