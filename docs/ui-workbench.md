# Flowdesk 工作台界面

首页围绕“行情观察 → 事件研究 → 私有工作台”组织。顶部三个任务链接定位到真实页面区域；接入数据源和刷新快照保留现有绑定。未连接、加载、错误、缺失值与不可用状态继续由原模块提供，不补市场统计或研究评分。

行情区保留市场选择、自选添加、交易日查询、筛选、排序和导出。研究入口按“资金区间与成交结构、资金事件与后续价格、尾盘证据、有效性与边界”分组，原有功能仍使用同一按钮ID和业务模块。

## 私有工作台

打开弹窗不会开启会话或读取台账。未开启时只显示说明与“1 开启本机会话、2 选择或创建账户、3 选择任务并核对”。线上页面提示进入本机看板，不能发起本机私有请求。

开启既有本机会话后，账户选择、刷新版本、连接提示与操作状态保持可见。六个任务面板分别处理：

| 页签 | 工作内容 | 稳定标识 |
| --- | --- | --- |
| 账户概览 | 创建账户、查看数量与账面成本、展开事实审计 | `overview` |
| 记录操作 | 追加期初、成交、现金或更正事实 | `record` |
| CSV导入 | 选择文件、解析、核对、重新冻结并确认导入 | `import` |
| 事件证据 | 人工录入来源、独立时间与事件版本 | `evidence` |
| 研究档案 | 支持与反面证据、触发与失效条件、冻结报告 | `research` |
| 压力实验室 | 主动载入已有授权快照，手填价格与情景 | `stress` |

页签点击、左右方向键、Home和End立即切换当前任务；Tab进入当前面板，隐藏面板使用`hidden`和`inert`退出键盘遍历。切页从任务顶部开始，保留未提交输入、账户选择和CSV预览状态，不访问API。表单保持各自独立，其他面板的必填项不参与当前表单校验。

长规则放在可用键盘展开的说明中；未知成本、明确零费用、人工证据未核实与研究冻结语义直接可见。关闭弹窗回到账户概览，由既有`watchDialogClosure`同时处理原生close和后台open属性移除，清空敏感内容与会话。

## 样式与接入

继续使用既有深色令牌、绿色/红色资金方向、原品牌标记和macOS苹方/Windows微软雅黑字体。主要控件为40–44px，数字使用等宽数字；新增交互过渡150ms，并尊重减少动态效果设置。表格和页签各自滚动，私有任务内容在弹窗内部滚动。

新增`dist/workspace-nav.js`只管理DOM可见性与焦点，通过`private.js`可选挂载；没有URL、浏览器存储、网络或私有客户端依赖。现有模拟DOM缺少导航模块时仍兼容。实际页面需要父任务先把`/workspace-nav.js`加入静态资源允许列表，并与更新后的HTML、CSS和private.js一起提供。导航脚本必须位于private.js之前，当前入口已按此顺序引用并更新缓存版本。

稳定属性为`data-workbench-section="market|research|private"`和`data-workspace-tab` / `data-workspace-panel`，面板ID为`private-panel-<标识>`。私有页签状态仅存在当前DOM与内存，关闭即重置。后续指标功能可由父任务独立接入，本次未增加占位按钮。
