# 私有台账、事件与研究使用指南

原有行情、资金事件研究、技术与期权观察继续使用。私有工作台新增本机USD正股账本和人工证据存档，不连接券商账户、不下单，不引入第三方项目框架或付费模型。

## 本机开启与私有目录

启动现有本机服务，在其同源页面点击“私有台账 / 研究”，再点击“开启本机会话”。配置了FLOW_TOKEN时，在私有入口重新输入；不会从行情配置、URL或浏览器持久存储读取。刷新页面/关闭工作台会清空前端会话与私有DOM。GitHub Pages入口只提示打开本机页面，不能连接或读取本机私有接口。

默认存储在macOS `~/Library/Application Support/Flowdesk/private/portfolio.sqlite3`，也可在服务启动前设置 `FLOWDESK_PRIVATE_DIR` 到独立目录。目录700、数据库600；禁止放在任意Git仓库、dist或其符号链接下。原始CSV行、冻结预览和研究报告正文都在此私有库，不写入dist、市场缓存或Git。仅通过验证的业务请求才初始化私有库；会话握手本身不初始化库。

私有API只接受POST JSON；包括读取在内均要求直接loopback peer、可信本机Host、精确同源Origin、内存X-Flowdesk-Session，配置FLOW_TOKEN时还须Authorization。服务重启会换会话令牌。没有跨源CORS、URL令牌、公共网页桥接或服务端来源URL抓取。

## 账户、期初和成交

1. 创建一个USD账户，选择当前账户。
2. 录入带截止日期的期初正股；成本不明确就留空。期初成本字段为总成本，不是每股价。多个标的期初使用同一个日期。
3. 只有确知现金余额时才录入同日期“期初现金”。未录入时，现金余额是未知；“账本现金变化”仍可计算，不能冒充总现金或权益。
4. 录入期初截止日之后已成交的买卖。每股价、数量、该笔费用分开，确认无费才填0。入出金只影响现金流，不当投资收益；分红、独立费用单独记录。
5. 拆股填写新股数/旧股数比例；保持总成本。底仓、短线、未分组为研究分组，不是独立税务批次，也不是产品版本。
6. 要更正时，展开审计取得最新有效原事件ID；选择替代事实的动作（例如“已成交买入”），填入完整正确事实、“替代原事件ID”和更正原因。界面自动继承原来源、真实执行ID及参考号，在同一批次追加作废和替代。原事件已在前次操作作废时，只追加替代。原文与原ID仍不可变，替代产生新审计ID并以 `replaces` 关联原ID；不要删除或捏造执行编号。连续更正应关联最新替代事件，不能从已替代的旧事件分叉。

API更正同样使用 `events/append`：同批传入 `kind=void,target=原事件ID,reason=原因` 和带 `replaces=原事件ID` 的完整替代事实；替代的 `source` 及已有 `external_id` 必须与原事实一致。前次已作废时省略void。已作废历史的执行号不能被普通CSV或不带关联的事实重新占用，其他有效事实的身份也不能冒用。涉及多条下游数量冲突时，在同一API批次更正相关事实；失败整批回滚，UI也不会删除历史来绕过校验。

当前成本为移动加权账面成本，非税务收益。未知底仓成本会传播到后续卖出损益；全部平仓后新买入可重新有已知成本，过去未知损益仍未知。不支持期权、卖空、wash sale、转仓税批、多币种精确收益或实时估值。没有完整价格/成本时浮动损益、总回报保持null。

## CSV：预览、选择、重新预览、确认

仅使用USD账户的UTF-8 Schwab CSV，已支持表头：

```text
Date,Action,Symbol,Description,Quantity,Price,Fees & Comm,Amount
```

买卖要求费用列明确，Date接受MM/DD/YYYY并保留日期精度，不补逐笔时刻。明确执行号列Execution ID可作唯一身份；Order ID及源行号不作去重键。Buy、Sell、Cash Dividend、Deposit、Withdrawal、Fee只按明确含义映射；不明确的转账、再投资、期权等保留原文待核实。Stock Split导出数量不一定是比例，因此CSV行待核实，确认后手工录入比例。金额与数量/价格/费用不一致也不自动纠正。

选择文件后点“解析预览”，展开各行核对原文。同日混合买卖或会改变分组的顺序不明时，填写逐笔人工确认的顺序；不以原CSV倒序、行号或买入优先推断。也可使用API提供确知的带时区执行时间，必须与美东交易日期一致。

相同无ID事实提示疑似重复，可能是真实同价同量分笔。新增真实Execution ID若匹配既有无ID事实，或同批仍有无ID的同事实行，也必须人工消歧，不能自动再记一笔。若为同一笔，取消选择并使用上述更正关联原记录；旧记录没有执行号时，可在替代事实中补入已核实的真实执行号。若确为独立分笔，填写独立参考号并勾选“确认此笔独立事实”，真实执行号原样保留。参考号不是伪造执行号，不能为了消除提示随便填；已存在的执行号或参考号不能普通重复导入。

修改选择、参考号或顺序后，点击“按所选内容重新预览”，核对回显的确认内容和快照，再“确认冻结预览并导入”。预览15分钟有效且仅能确认一次；账户revision变化必须重新预览。确认只接收预览ID和摘要，不接受重传成交正文；全部记录在同一事务写入。取消选择的问题行不会被悄悄当成已处理，原文仍显示在预览中供复核，完整CSV与所有行的问题随有效冻结预览保存在私有库中。未生成可确认预览的文件仅保留在当前界面内存，关闭前请保留原文件以便核实。

## 事件与研究冻结

事件类型包括新闻、财报、宏观和政策，可关联一只正股或global。标题、来源及HTTP(S) URL必填；服务不会访问此URL。人工事件永远标为未自动核实，不接受客户端自称已核验。

- published_at：来源声称的发布时间，可未知。
- available_at：人工声称首次可知时间，可未知，不能早于声称发布时间。
- first_seen_at：本系统实际首次录入时间，由服务器生成，修改版本不能回填。
- captured_at：本版本实际存档时间；当前为手工录入时间，未接入远程抓取。

时间要含时区。实际值、预期、前值、修订值、期间、单位各自保存，空白即null。修改事件只追加新版本。

选择支持与反面证据，填写人工论点、触发及失效条件后保存研究。截止空白即保存当时；历史截止需填含时区ISO时间，不能选择未来。保存时冻结账户snapshot/revision和证据完整内容/版本。发布时间、声称可知、实际首次记录及该版本存档时间都不晚于截止才满足时间要求；即便满足，人工来源仍未自动核实。未来或未知时间证据只作为线索和缺口。历史补录不会伪装当时已知。若有截止前实际存档的旧版本，使用该版本。

研究持仓按当前更正后的账本版本重放，不声称恢复历史当时系统已知的账户版本。日期精度的当日事实在完整美东日期结束前不作为确知持仓；其后同标的依赖事实连同排除，避免截出超卖子集。其他独立确定持仓继续可用。真实时刻已知且独立的事件按执行时间截断，明确晚于截止的事实不制造持仓不确定性。

快照 `position_gaps` 逐标的列出 `uncertain_event_ids`、`dependent_event_ids` 和 `known_partial_quantity`；受影响持仓 `quantity_status=known_partial`，`quantity` 至多是已知子集，不能当作截止总量。没有已知持仓时 `quantity=null`，即使已知子集为0，也不声称确定0股。`cost=null`，子集成本另存 `known_partial_cost`。报告和界面均明确显示“截止总量未知 / 仅已知部分”。`cutoff_exclusions` 给出逐笔日期和排除原因，兼容保留原排除ID列表；质量增加 `position_timing_uncertain` 和 `partial_ledger_totals`。存在当日不确定事实时 `totals_status=known_partial`，现金、现金变化、费用、分红、资金流和已实现损益汇总均为null，仅已知子集留在 `known_partial_totals`，不冒充完整账户总额。完整美东日期结束后可重新冻结完整日事实，旧研究不改写。

历史研究可查看并下载JSON/Markdown。报告先列持仓日期、版本与证据缺口，然后区分账本事实、人工判断、支持/反面证据及条件式观察。Markdown来源URL在输出前重新验证HTTP(S)、无凭证、无控制字符或反斜杠歧义，使用受控尖括号链接；域名和连字符不加反斜杠，尖括号及引号等编码。标题及正文继续防止HTML/Markdown注入。证据界面只为已由服务端验证的HTTP(S) URL提供带 `rel="noopener noreferrer"` 的链接，显示时再次检查协议；不会自动抓取链接。导出保存到仓库外；前端使用内存Blob下载，不在服务端生成公开文件。不生成LLM胜率、自动评分或自动买卖，不声称接入BLS/IR自动抓取。

## Hermes只读CLI

以下命令由父代理在明确选择私有目录后执行；本轮实现未读取真实账户。CLI使用SQLite只读URI，不创建目录、数据库、表或记录，只写stdout。未指定目录时沿用FLOWDESK_PRIVATE_DIR及默认目录。

```bash
.venv/bin/python private_cli.py --directory /独立私有目录 accounts
.venv/bin/python private_cli.py --directory /独立私有目录 portfolio --account 账户ID
.venv/bin/python private_cli.py --directory /独立私有目录 research --account 账户ID
.venv/bin/python private_cli.py --directory /独立私有目录 export-report --id 研究ID --format markdown
```

portfolio的`--as-of YYYY-MM-DD`是当前账本版本的交易日期截断，不是历史当时已知版本。冻结研究导出应使用export-report。父代理随后连接旧持仓JSON与现有Hermes报告，保持回退；当前未迁移真实持仓或配置定时任务。

## 父代理Task5真实验收

父代理已反馈基本合成链路的真实浏览器验收通过，并补入后台标签页移除dialog.open时的MutationObserver清理及回归；本轮保留该补丁。以下步骤用于父代理再次核验，本轮修复只执行离线合成测试，不另启服务或浏览器。

1. 独立安全/计算审查后，使用授权测试根目录下新的子目录作为FLOWDESK_PRIVATE_DIR，并选额外loopback端口启动新服务；不要复用真实数据库或终止旧服务。
2. 浏览器打开该端口的本机页面，开启会话，新建合成账户；录入TEST期初3股、2026-01-01、成本空白，再录入同日期现金期初1000。
3. 上传仓库内 `tests/fixtures/portfolio/schwab-synthetic.csv`，预览后确认。预期TEST数量4、成本未知、现金余额992.2、账本现金变化-7.8、分红0.5、费用0.3、已实现损益未知。重复上传应提示疑似重复，不自动合并或自动再记账。
4. 录入合成事件，选择支持/反面证据，保存研究并下载两种格式。再修改持仓、追加事件新版本，确认旧报告字节内容不变。试历史截止、未知时间和未来发布时间，确认只作线索。
5. 用外部Origin、恶意Host、缺会话令牌、缺已配置FLOW_TOKEN及OPTIONS分别请求，确认无私有数据/令牌及CORS。握手前和拒绝请求后检查私有库未被初始化。关闭对话框后私有DOM与令牌清空；线上页面不发私有请求。
6. 增补核验三项P1：旧无ID事实后补执行号须人工消歧；同日日期买入与精确卖出研究保存成功且明确截止总量未知；保留执行号更正费用后数量不翻倍、原审计不变。检查来源链接点击及复制。重跑本节点回归后，由父代理处理后续真实持仓导入、Hermes桥接、Git节点提交和发布；新增修复的真实浏览器复验尚由父代理完成。
