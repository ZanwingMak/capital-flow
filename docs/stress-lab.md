# 持仓压力实验室

在本机“私有台账 / 研究”弹窗内，用当前已授权的USD正股快照比较人工假设情景。**假设情景、不是预测。** 账本仍是唯一事实来源，实验不改变数量、成本或分组，也不写入研究记录。

## 使用

1. 在既有私有工作台开启本机会话，选择合成或本人授权的USD账户。
2. 在“持仓压力实验室”点击“载入当前账户持仓”。只有此操作才复制标的、数量与数量状态、分组；载入前不会复制持仓，实验室本身不能握手、读取数据库或请求快照。
3. 核对来源持仓日期和revision。手填USD每股参考价格，以及统一的参考价格时间，例如 `2026-01-02T15:30:00Z`。必须是有效且不在未来的带时区ISO时间，不会自动填入当前时间、获取报价或从账面成本推导价格。填写者应保证这些价格对应所填时间，系统无法核验人工报价来源。
4. 选择假设下跌5%、10%、20%，或手填全局冲击。单股冲击空白继承全局，明确填写 `0` 表示该股不变；填写 `-100` 表示情景价格为零。全局冲击不能留空，逐股覆盖也不能使无效全局输入变为有效。
5. 点击“计算假设情景”，检查覆盖、逐股原因和分组表。任何输入变动会立即删除旧结果，需重新计算。“清除单股覆盖”保留价格、时间和全局冲击；“清空实验”回到待载入状态。

每个输入有标签，表格支持键盘聚焦和窄屏横向滚动。文字和错误均为中文，标的始终按纯文本展示。

## 数值口径与缺口

- 参考市值 = 完整已知数量 × 人工参考价格。
- 情景每股价 = 人工参考价格 ×（1 + 冲击 / 100）。冲击范围为 `[-100, 1000]`%，不会产生负情景价格。
- 情景市值 = 完整已知数量 × 情景每股价；美元变化 = 情景市值 − 参考市值。
- 金额显示两位小数，汇总使用未格式化数值后统一显示。因此逐行显示金额经四舍五入后相加，可能与汇总相差数分。使用JavaScript有限数值近似计算，不声称券商精确核算。

数量/参考价格只接受普通十进制有限数值，范围为0至1万亿。拒绝千分位逗号、货币符号、科学计数法、畸形文本、负数及非有限值。每次乘积和累计金额都检查有限性，价格或金额不得超过1万亿美元；正数乘积下溢成0也拒绝。累计超限时停止展示总额及分组总额，不以静默丢弃行来修复汇总。

数量为空、状态未知、`quantity_status=known_partial` 或 `position_gaps` 中存在的标的均不能参与计算。已知部分哪怕为0，也不是确定总数量。缺口中没有对应持仓行的标的仍会显示，避免消失在覆盖分母中。参考价格缺失、无效冲击或超限金额也逐行列出原因；明确的0数量、0参考价格、0冲击则保留为真实零值。

覆盖显示“可计算标的数 / 全部载入标的数”，并列出未覆盖标的；它不是按市值加权的覆盖率。只对同一可计算集合汇总参考市值、情景市值与美元变化，无覆盖保持未知。没有组合百分比回报，也不将局部覆盖除以账户净值、现金或成本。这里的基准只是**已覆盖正股参考市值**，不代表账户NAV、全部资产或投资收益。

底仓 `core`、短线 `tactical`、未分组 `ungrouped` 使用同一覆盖集合汇总；未知分组按未分组保留，实验不能修改原分组。没有覆盖行的分组显示未知金额，真正被覆盖且为零的分组显示 `0.00`。

## 生命周期与隐私

人工价格、参考时刻、冲击和结果只在当前模块闭包与DOM中存在。不写浏览器持久存储、URL、日志、服务端或公开文件，也不提供实验导出。

切换账户、刷新版本、关闭私有弹窗立即擦除实验输入、结果DOM和内存状态。即使刷新返回相同revision也清空，避免沿用旧实验。上下文账户、revision或持仓日期变化时需重新显式载入；异步返回的旧账户快照和旧DOM事件不能恢复实验。沿用既有 `watchDialogClosure` 的原生close及open属性观察，后台标签页移除open属性也会清理，不依赖延迟到达的close事件。

实验室没有API客户端；静态资源只增加 `stress-lab.js` 白名单。现有本机同源、Host、会话令牌及FLOW_TOKEN保护保留，GitHub Pages仍不能读取本机私有API。未增加数据库、schema、业务API或外部行情接入。
