# Flowdesk 本机启动

macOS 用户在项目目录双击 **启动Flowdesk.command**。页面和数据 API 会一起启动，默认地址为 `http://127.0.0.1:8788/`；启动终端关闭后，后台页面仍可访问。

首次使用前，请自行安装 Python 3.10 或更新版本（包含 venv/pip），并安装富途 OpenD 至 macOS 的 Applications 目录。启动器优先使用已有 `.venv`；缺少环境时在项目内创建，依赖缺失时才联网安装 `requirements.txt`，不会安装系统软件或修改全局 Python。首次联网安装失败时检查网络后重试；不完整的 `.venv` 需手动移走后再试，启动器不会覆盖。

富途登录必须由本人在 OpenD 中完成，并按其设置启用本机 API。已有 OpenD 会被复用；未运行时尝试在后台打开已安装的 App，并有界等待。只有只读状态确认行情已登录，才显示 Futu 就绪；具体市场行情权限仍以实际查询为准。未登录、App 缺失或接口不可用时仍可打开网页，显示“部分就绪”并返回非零状态；处理提示后再次双击即可。

Alpaca 功能需要自行通过既有环境变量或本机 `.env` 配置 `APCA_API_KEY_ID` 和 `APCA_API_SECRET_KEY`。启动器只报告配置是否齐全，权限未验证；缺少密钥不影响基本页面。Cboe 无需密钥，数据缺少明确时间语义时仍保守拒绝当前信号，也不阻止启动。

后续直接双击入口即可。重复启动会识别并复用同一项目的健康服务，同时双击由启动锁串行处理。目录可以包含空格；移动或复制项目后，其健康身份会改变。

终端验收可在项目目录执行：

```bash
./启动Flowdesk.command --no-browser
./启动Flowdesk.command --status
```

`--no-browser` 不自动打开浏览器；`--status` 只检查，不安装、不启动、不写文件。退出码 `0` 表示网页与 Futu 就绪，`2` 表示部分就绪或状态检查发现未就绪，`1` 表示启动失败。Alpaca 配置齐全不代表鉴权或 SIP 行情权限通过。

默认网页与 OpenD 分别使用 `127.0.0.1:8788`、`127.0.0.1:11111`。终端中已有的 `FLOW_PORT`、`FUTU_HOST`、`FUTU_PORT` 会被继承；Finder 不保证继承终端配置。此入口只允许网页绑定 `127.0.0.1` 或 `localhost`，不开放远程访问；配置远程 OpenD 时仅进行只读核验，不尝试为远程机器启动 App 或登录。

若网页端口被其他服务、另一份项目、旧版无项目标识的服务或无法认证的服务占用，启动器会明确失败且不结束任何现有服务。请先核实占用者并自行处理，或使用空闲的 `FLOW_PORT`。已有服务受 `FLOW_TOKEN` 保护时，启动入口需继承相同令牌；令牌不会被放进网址，网页仍按原有认证方式访问。

服务日志、PID 记录和锁文件仅位于项目 `.data/`，分别为 `flowdesk.log`、`server.pid`、`startup.lock`，均被 Git 忽略。启动失败时只显示安全提示及日志位置，不主动输出日志内容；排查时不要公开 `.env`、日志或私有行情缓存。PID 可能在服务退出后残留，不能凭 PID 文件直接结束进程；本次不提供自动停止入口。

本工具用于本机只读市场数据和研究，不下单、不交易；Windows 分发包不在此次调整范围。实现及离线验证见 [节点5记录](docs/changes/05-one-click-startup.md)。
